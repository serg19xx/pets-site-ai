# Local partners (soft launch)

Краткое ТЗ. Партнёры = небольшие локальные бизнесы (ветклиники, приюты, зоомагазины, груминг), **не пользователи сайта**.

## Цель

- Им: бесплатная витрина (логотип + ссылка на их сайт)
- Нам: доверие («нас показывают клиники»), повод для офлайн/QR, не холодный спам в FB
- Деньги / доля / комиссии — **нет** на этом этапе

## Объём сейчас

- В сайдбаре **до 6** логотипов (`LOCAL_PARTNERS_SIDEBAR_LIMIT`)
- Если партнёров больше — ссылка **See more…** → страница `/partners` со всем списком
- Ручной список: `web/data/local-partners.ts` + лого в `web/public/partners/`
- Согласие устно или короткое письмо: «можно показать лого и ссылку; снимем по запросу»

## UI

- Блок **Partners** в **правом сайдбаре** (`AsidePartners` в `AppAside`) на основных экранах
- Только логотипы (на полной странице — имя + регион)
- Клик → их сайт / Instagram в новой вкладке (`target="_blank"`, `rel="noopener noreferrer"`)
- Подпись «Local partners» / «Partenaires locaux»
- На мобилке сайдбар скрыт: полный список на `/partners`

## Аккаунты в системе — сознательно НЕ делаем пока

Партнёры **без активного аккаунта** в Pet Friends.

Почему отложено:
- неизвестно, захотят ли они кабинет
- неизвестно, нужен ли нам кабинет для них (каталог услуг, заявки, чат…)
- аккаунт = поддержка, роли, модерация — рано

Когда пересматривать: если 5 партнёров стабильно работают и сами просят «управлять карточкой» или появляется заявки/услуги внутри продукта.

До тех пор партнёр = **внешняя ссылка + лого**, не `users` / не seller / не admin.

## Не входит в этот этап

- Оплата, комиссия, промокоды
- Рекламный кабинет / статистика кликов (можно позже простой счётчик)
- Маркетплейс услуг клиник
- Автоматический онбординг партнёров
- Обещания «рекомендуем» / рейтинги без договорённости

## Критерий готовности (минимум)

1. Записи в `local-partners.ts`: имя, лого, URL  
2. Блок справа на десктопе (до 6 лого; See more → `/partners`)  
3. Клик уводит на сайт партнёра  
4. Можно убрать партнёра правкой конфига + файла лого

**Трекер поиска и ответов:** [`partners-outreach-tracker.md`](./partners-outreach-tracker.md)

## Текст оффера клинике (черновик)

> Soft launch Pet Friends (сообщество хозяев питомцев в регионе).  
> Хотим показать вас как local partner: логотип + ссылка на ваш сайт в боковой панели.  
> Бесплатно, без договора на долю. Снимем по вашей просьбе.  
> Если ок — пришлите лого (PNG/SVG) и URL.

## На потом (не строить сейчас)

### Become a Partner

Когда ручных 5 мало и появятся договоры/оплата:

1. Кнопка **Become a Partner** (сайдбар или `/partners`)
2. Короткая форма → заявка **админу** (in-app + email)
3. После договорённости: оплата → размещение лого + ссылки
4. Партнёр по-прежнему может остаться **без полноценного кабинета**, пока сами не попросят управлять карточкой

Не смешивать с текущими 5 бесплатными soft-launch партнёрами: у тех отдельный статус (complimentary / founding).

### Контент по регионам (обязательно заложить в голове продукта)

Если аудитория вырастет за пределы одного города/страны:

- Пользователь в **Торонто** должен видеть контент, релевантный **Торонто** (питомцы, лента, объявления, партнёры) — не чужой регион по умолчанию
- Партнёры в сайдбаре тоже **региональные**: клиника в Монреале не торчит у всех в Торонто
- Регион = город / metro area на старте расширения (не обязательно страна целиком)

Пока soft-launch локальный — достаточно одного региона в уме (Quebec / текущий город).  
Перед масштабом: город в профиле/сессии + фильтры галереи, ленты, маркета, партнёров. Без этого «Become a Partner» и платное размещение размажут чужие рынки.
