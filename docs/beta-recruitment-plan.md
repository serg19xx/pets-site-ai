# Beta recruitment plan (soft launch)

Goal: recruit **founding testers** who try the site and leave feedback in-app — not advertise a finished product.

**Invite (everywhere):** https://pb.websmith-shop.com/invite  
**In-app feedback:** already available for testers (`/app/feedback`).

Related: [beta-social-posts.md](./beta-social-posts.md), [social-groups-outreach.md](./social-groups-outreach.md), [partners-outreach-tracker.md](./partners-outreach-tracker.md), [demo-showcase-content.md](./demo-showcase-content.md).

## Message (always)

Order matters — people skim and bounce if it sounds like “we need QA”:

1. **What it is** — a pet owners’ club (Montreal / QC) where the *animal* has a place: gallery, voice, light virtual life.
2. **Why it’s different** — not only photos for humans; pets can “speak” a little and exchange a short hello; plus feed + classifieds.
3. **What we ask** — try it, poke around, leave honest notes in Feedback.
4. Soft beta — **not** a finished app; limited founding spots.
5. Same link every time; rotate angle (see Day 1–7 drafts + [social-groups-outreach.md](./social-groups-outreach.md)).

Do **not** lead with jargon alone (“soft launch / founding testers”) without the benefit.  
Do **not** sell “join the best pet social network.” Do **not** promise cash for testing.

## Where to recruit

### A. Social (already started)

| Channel | How | Priority |
|---------|-----|----------|
| Facebook pet groups (MTL / QC) | Soft post; link often in first comment; collage OK | P0 — done once; reminder only after 2–3 weeks if post survived |
| Instagram (own profile) | Post + Stories; bio → `/invite` | P0 next |
| TikTok / Reels | 15–30s screen + “looking for testers” | P1 |
| Reddit (`r/montreal`, pet subs) | Only if rules allow; often comment first, no hard sell | P2 |
| Discord / Telegram pet chats | One message in promo channel or with mod OK | P2 |
| Nextdoor (if active nearby) | Neighbours with pets | P2 |

FB detail + copy: [social-groups-outreach.md](./social-groups-outreach.md).

### B. Outside social (high trust, small volume)

| Channel | How | Priority |
|---------|-----|----------|
| Personal messages | 10–20 owner friends (WhatsApp / iMessage / email) | P0 — do first |
| Local partners | Clinic / shop / groomer: QR or flyer “testers wanted” at desk | P0 with partner list |
| Dog parks / walks | Card or QR, one sentence | P1 |
| Campus / student pet clubs | Notice board or campus FB | P1 |
| Meetup / adoption events | Verbal + QR, no booth required | P1 |
| Kijiji-style “volunteers” | “Looking for site testers (pet owners)” — not app ads | P2 |
| Breed / rescue email lists | One short ask + invite | P2 |
| Local founder / maker communities | “Need user tests,” not growth spam | P2 |

### C. Paid ads

Defer until organic testers exist and invite flow is proven. If used later: creative must say **beta testers / feedback**, not “download the app.”

## Simple sequence (this week)

Do in order — stop when you have enough conversations, not vanity reach.

1. [ ] **Personal:** message 10 people with pets (FR or EN). One link. Ask them to try + feedback in the app.
2. [ ] **Instagram:** one feed post or Story with collage + invite in bio/comment.
3. [ ] **TikTok or Reel (optional same day):** 20s “not finished — need testers.”
4. [ ] **One partner:** ask if a QR for testers can sit at the counter (see partners tracker).
5. [ ] **FB:** do **not** re-blast the ~30 groups yet. Check which posts are still live / pending; note in outreach tracker. Reminder only where there was interest, after 2–3 weeks.
6. [ ] **Demo content:** keep a few polished showcase pets/posts so the public site is not empty; hide/clean obvious junk (see below + [demo-showcase-content.md](./demo-showcase-content.md)).

## Demo / fake data policy (prod)

**Keep** a small showcase so Animals / Feed / Marketplace do not look abandoned while real users arrive.

**Do not** leave keyboard-mash titles, random screenshots, or empty posts that scream “test.”

| Keep | Remove or fix |
|------|----------------|
| 2–5 demo owners (`@petsbook.local`) with MTL-like names | Personal junk accounts that look broken |
| Pets with normal names + species SVG OK until real photos | `Seed Pet %` leftovers, empty feed posts |
| A handful of readable posts + listings | Duplicate spam listings |

Public UI shows **nickname / name**, not `@petsbook.local` emails — still make copy and photos look human. Local/dev can keep the same demo password for login tests; production visitors should never need those accounts.
