# Founding beta — social post drafts

Recruit **founding testers**, not a finished-app launch.  
Benefits come **later for active testing** (bonus points / complimentary services) — not cash, not a job.

**Invite link (everywhere):** https://pb.websmith-shop.com/invite

“Day 1…7” = numbered variants to rotate/remind — not a fixed calendar. Repeat with a different angle so the message sticks.

---

## Week of posts

### Day 1 — who we need

**EN:** Soft launch. Looking for pet owners to test Pet Friends and leave honest feedback. Limited founding spots.

**FR:** Soft launch. On cherche des propriétaires pour tester Pet Friends et donner un retour honnête. Places limitées.

### Day 2 — what to do

**EN:** Join as a founding tester → add a pet → try gallery / friends hello → send feedback in the app.

**FR:** Devenez testeur fondateur → ajoutez un animal → essayez la galerie / le “hello” entre animaux → envoyez un feedback.

### Day 3 — benefits (careful)

**EN:** Active testers: later bonus points and/or complimentary services when paid features launch. Thank-you for testing — not cash, not a job.

**FR:** Testeurs actifs : plus tard points bonus et/ou services offerts. Un merci pour les tests — pas d’argent, pas un emploi.

### Day 4 — hook (without “finished product”)

**EN:** We’re testing a small idea: pets can “meet” and exchange a short hello — for owners’ fun. Help us improve it.

**FR:** On teste une petite idée : les animaux se “rencontrent” et échangent un court bonjour — pour le fun des propriétaires. Aidez-nous à l’améliorer.

### Day 5 — limit

**EN:** Founding beta seats are limited. If you like shaping early products with pets in mind — claim a spot.

**FR:** Les places founding beta sont limitées. Si vous aimez façonner un produit tôt, avec les animaux en tête — prenez une place.

### Day 6 — for groups (softer)

**EN:** Hi — recruiting a few pet owners for a soft-launch beta (community + pet profiles). Feedback welcome. Invite page in comments.

**FR:** Bonjour — on recrute quelques propriétaires pour une bêta soft launch (communauté + profils animaux). Feedback bienvenu. Lien d’invite en commentaire.

### Day 7 — reminder

**EN:** Still looking for founding testers this week. Try it, break it, tell us. Invite: pb.websmith-shop.com/invite

**FR:** On cherche encore des testeurs fondateurs cette semaine. Testez, cassez, dites-nous. Invite : pb.websmith-shop.com/invite
