# Next product bets (soft launch)

Краткое ТЗ «что дальше», чтобы не потерять направление.  
Не бэклог на год — **следующие ставки после текущего MVP**.

## Уже есть

- Галерея питомцев
- Лента постов / новости
- Маркетплейс объявлений
- ИИ (голос / черновики / virtual life)
- Приватные запросы (medical share 2h, дружба питомцев и т.п.)

## Ступор без клиентов — правило

Без обратной связи **не плодить фичи**. Один weekly experiment. Смотреть клики: medical request, friendship, marketplace, AI.

## Приоритет (что добавить)

### 1. События вокруг питомца (P0)

- Вакцинация, стрижка, выставка, прогулка, день рождения
- Календарь + напоминания (email / позже push)
- Связка с Medical и AI-голосом

**Критерий готовности:** хозяин создаёт событие → получает напоминание → опционально пост/голос в ленте.

### 2. Локальность «рядом со мной» (P0)

- Питомцы / объявления / активность по городу (Quebec soft-launch)
- Гео или город в профиле / объявлении

**Критерий:** лента или галерея фильтруется по локации.

### 3. Потерялся / найден (P1)

- Срочный тип карточки/поста: фото, описание, контакт, гео
- Высокая повторная ценность визита

**Критерий:** гость видит lost/found без логина; хозяин создаёт за 2 минуты.

### 4. Круг хозяина (P1)

- Друзья хозяев, няня, вет как контакты (не полноценный Facebook)
- Заготовка «owner circle» на публичной странице питомца

### 5. Паспорт питомца пакетом (P1)

- Прививки + чип + страховка + сертификаты
- Одна кнопка «поделиться на N часов» (как medical share)

### 6. Сервисы лёгким слоем (P2)

- Выгул / груминг / ситтер / вет — карточка + заявка
- Без оплаты внутри на старте

### 7. Local partners в сайдбаре (P0 маркетинг / доверие)

- До 5 ветклиник / приютов / магазинов: лого → их сайт
- Блок справа (`AppAside`), **без аккаунта партнёра в системе** (пока неизвестно, нужен ли)
- Детали: [`partners-soft-launch.md`](./partners-soft-launch.md)
- Позже: **Become a Partner** → заявка админу → договор/оплата → лого; контент и партнёры **по региону** (Торонто ≠ Монреаль)

## Явно не сейчас

- Ещё одна «Instagram-соцсеть»
- Полный чат между всеми
- Платежи / подписки до 20–50 живых пользователей
- Много AI ради AI

## Окно 4–6 недель (черновик)

| Недели | Фокус |
|--------|--------|
| 1–2 | Календарь событий + напоминания |
| 3–4 | Локальный фильтр / город |
| 5–6 | Lost & found **или** паспорт-share (что сильнее по фидбеку беты) |

## Как собирать сигнал без SEO

1. 10–20 знакомых хозяев: зачем зашли / что сделали / чего не хватило
2. Смотреть реальные клики в бете
3. Один эксперимент в неделю, не пять фич параллельно
