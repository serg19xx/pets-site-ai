# Learn contributors tracker

Manual list (same idea as [partners-outreach-tracker.md](./partners-outreach-tracker.md)).  
**No site account required.** Attach a user later only if they want to edit or answer consultation requests.

Plan: [learn-and-consultations.md](./learn-and-consultations.md).

## Statuses

| Status | Meaning |
|--------|---------|
| `idea` | We would like them to write or consult |
| `asked` | We contacted them |
| `guest` | One-off guide; we publish |
| `regular` | Ongoing series |
| `partner` | Clinic/shop content |
| `consults` | Willing to take questions later |
| `no` | Declined |
| `skip` | Not a fit |

## Kind

`guest` · `regular` · `partner` (relationship). Consult flag is separate (`consults` yes/no).
